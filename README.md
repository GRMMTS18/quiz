# Sistema de Quiz

## 📌 Descrição
Aplicação web interativa desenvolvida para realização de perguntas e respostas, com foco em lógica de programação e interatividade.

## 🚀 Funcionalidades
- Exibição de perguntas
- Seleção de respostas
- Validação de respostas
- Feedback ao usuário

## 🛠️ Tecnologias
- HTML
- CSS
- JavaScript

## 💻 Meu papel no projeto
- Desenvolvimento da lógica com JavaScript
- Criação da interface
- Implementação da interação com o usuário

## 📸 Preview
Adicione prints do sistema

## 💡 Objetivo
Projeto desenvolvido para prática de lógica de programação e interatividade em aplicações web.
